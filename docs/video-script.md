# B站番剧批量三连｜教程视频分镜与口播脚本

> 用途：用 OBS 录屏 + 后期加字幕，产出一条发 B 站的教程短视频。
> 建议时长：约 2 分钟｜风格：技术教程、节奏明快｜BGM：轻快电子乐，音量压到人声的 20% 以下。

## 录屏前准备

- 浏览器登录 B 站（确保有 `SESSDATA`、有足够硬币）
- 浏览器已装 Tampermonkey（镜头 3 会演示安装，可先用无扩展的浏览器配置一套录制环境）
- 准备好仓库地址：`https://github.com/KadiiDou86/bili-batch-triple`
- 准备好两张面板截图：`docs/screenshots/panel-running.png`、`panel-finished.png`（镜头 2 用）
- OBS 建议 1080p、浏览器缩放 125%，鼠标指针加高亮，关键操作处后期放大 1.3 倍
- 录屏时先空录 3 秒，方便后期剪辑对齐

## 口播全文（连读版，约 380 字，方便提词器）

> 追一部几百集的番，一集集点三连，点到手酸？今天教你一招，让浏览器自己搞定。
>
> 这就是今天的主角——一个 Tampermonkey 脚本。装好之后打开番剧页，点几下，整部番的正片自动三连。它走的是 B 站官方一键三连接口，一次请求，点赞投币收藏全搞定。
>
> 第一步，给你的浏览器装一个"篡改猴"。Chrome 或 Edge 都行，打开扩展商店，搜索 Tampermonkey，点安装。装好后，浏览器右上角会出现这个小图标。
>
> 第二步，导入脚本。点开篡改猴图标，进入管理面板，找到"实用工具"，点击"通过 URL 导入脚本"。把仓库里的 raw 直链复制进来——注意是直链，不是仓库主页。粘贴，点安装，确认脚本信息后完成安装。
>
> 第三步，使用。打开任意一集番剧播放页，右下角会自动弹出面板，并读取整部番的剧集。"仅正片"默认勾选，预告花絮自动排除。选一个间隔，建议 3 秒以上，点开始，它就一集集自动三连，进度条走满就完成了。
>
> 中途关了页面也没关系，完成的集数记在本地，下次重跑自动跳过。脚本还支持自动更新，以后发新版点一下更新就行。
>
> 最后提醒：官方接口固定投 2 币、存默认收藏夹，硬币要备足；操作太快会触发风控，连续失败 3 次会自动暂停；这类自动化脚本可能有账号风险，请自行判断。
>
> 脚本开源在 GitHub，地址在简介和评论区。如果对你有帮助，不妨也给这个视频来个三连。
